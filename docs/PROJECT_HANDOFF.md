# 🤝 Project Handoff Guide

## 📋 Overview
Welcome to the **Cancer Multi-Agent System** repository. This document serves as a comprehensive onboarding and handoff reference for developers, researchers, and AI collaborators working on this project.

---

## 🎯 Project Mission
To build an intelligent, multi-agent collaborative AI system designed to assist oncology researchers and clinicians in data synthesis, biomedical literature retrieval, genomic/pathology analysis, and evidence-backed clinical workflow assistance.

---

## ⚡ Quick Start & Setup

### 1. Prerequisites
- **Python**: 3.10+ recommended
- **Git**: Configured with your GitHub credentials
- **API Keys**: Access keys for LLM providers (e.g., Google Gemini, OpenAI, Anthropic) and medical literature APIs (e.g., PubMed/NCBI).

### 2. Environment Setup
```bash
# Clone the repository
git clone https://github.com/Snigdha-0210/Cancer-multi-agent.git
cd Cancer-multi-agent

# Create and activate virtual environment
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On Linux/macOS:
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### 3. Configuration (.env)
Create a `.env` file in the project root:
```env
GEMINI_API_KEY=your_gemini_api_key_here
OPENAI_API_KEY=your_openai_api_key_here
NCBI_API_KEY=your_ncbi_api_key_optional
VECTOR_DB_DIR=./data/vector_store
```

## 🛡️ Critical Guidelines for Contributors
1. **Medical Disclaimer & Safety**: All outputs generated by agents are for research and decision-support exploration only—never direct unverified diagnostic advice.
2. **Citation Integrity**: Agents must provide verifiable citations (e.g., PMID, DOI, clinical guideline references).
3. **Privacy & HIPAA**: Never commit real patient Identifiable Information (PII/PHI). Use synthetic datasets only.
4. **Git Discipline**: Create feature branches, ensure tests pass, and keep documentation synced with code updates.
